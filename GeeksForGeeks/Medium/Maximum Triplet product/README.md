<h2><a href="https://www.geeksforgeeks.org/problems/maximum-triplet-product--170647/1">Maximum Triplet product</a></h2><h3>Difficulty Level: Medium</h3><hr><p><span style="font-size: 18px;">Given an array <strong>arr</strong>, find the maximum product that can be obtained by multiplying any three elements of the array. Return the maximum triplet product.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [1, 2, 3, 5]
<strong>Output: </strong>30
<strong>Explanation: </strong>(5)*(3)*(2) gives 30. This is the maximum possible triplet product in the array.</span>
</pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>arr[] = [-3, -5, 1, 0, 8, 3, -2]<strong>
Output: </strong>120
<strong>Explanation: </strong>(-3)*(-5)*(8) gives 120. This is the maximum possible triplet product in the array.</span>
</pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>3 ≤ n ≤ 5*10<sup>6</sup><br>-10<sup>-3</sup> ≤ arr[i] ≤ 10<sup>3</sup></span></p>
