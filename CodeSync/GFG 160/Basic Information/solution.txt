💡 Pattern: Add right → Size==K → Answer → Remove left


for (int r = 0; r < n; r++) {

    }

🟡 2. LONGEST VALID WINDOW (Variable Size)


💡 Pattern: Expand right → Invalid → Shrink left → Max


for (int r = 0; r < n; r++) {

    add(arr[r]);

    while (invalid()) {

        remove(arr[l]);

        l++;

    }

    ans = max(ans, r - l + 1);

}

💡 Pattern: Expand right → Valid → Min → Shrink left


for (int r = 0; r < n; r++) {

        remove(arr[l]);

    }

}

🧠 FINAL CHEAT SHEET


Fixed K     → Add → Answer → Remove

Longest     → Expand → Invalid → Shrink → Max

Shortest    → Expand → Valid → Min → Shrink

Count       → Valid → ans += window length

Exactly K   → AtMost(K) - AtMost(K-1)

Max/Min     → Monotonic Deque

Frequency   → HashMap / Array
