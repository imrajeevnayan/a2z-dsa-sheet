 ### 🚀 SLIDING WINDOW — Master Pattern Before Your Next DSA Interview


 **If you are solving Subarray / Substring problems, STOP memorizing questions.\

 Start recognizing the pattern. 👇**


 Sliding Window is one of the most useful patterns for converting many **O(N²)** brute-force solutions into **O(N)** solutions.  GeeksforGeeks


---


 ## 🟢 PATTERN 1 — FIXED SIZE WINDOW


 👉 Window size **K is fixed**


 ### 🔹 Basic


 1. Maximum Sum Subarray of Size K

2. Maximum Average Subarray

3. Maximum XOR of K Consecutive Elements


 ### 🔹 Frequency / Counting


 4. Count Distinct Elements in Every Window of Size K

5. First Negative Integer in Every Window of Size K

6. Count Occurrences of Anagrams

7. Find All Anagrams in a String


 ### 🔹 Maximum / Minimum


 8. Sliding Window Maximum

9. Sliding Window Minimum

10. Sum of Minimum and Maximum Elements of Every Window

11. Maximum MEX of All Subarrays of Size K


 These are the **foundation problems**. Master the basic `add → remove → update` movement first.  GeeksforGeeks+1


---


 ## 🟡 PATTERN 2 — VARIABLE SIZE — LONGEST WINDOW


 👉 Expand `right`\

 👉 Condition break ho → move `left`\

 👉 Maintain the **maximum valid window**


 ### 🔹 Must Do


 12. Longest Substring Without Repeating Characters

13. Longest Substring with K Distinct Characters

14. Longest Substring with At Most K Distinct Characters

15. Fruit Into Baskets

16. Max Consecutive Ones III

17. Longest Repeating Character Replacement

18. Longest Subarray with At Most K Distinct Elements

19. Longest Subarray with Sum ≤ K


 This pattern is essentially:


 **Expand → Check → Shrink → Update Answer** 🔥


---


 ## 🟠 PATTERN 3 — VARIABLE SIZE — SHORTEST / MINIMUM WINDOW


 👉 Expand until condition becomes valid\

 👉 Then shrink aggressively\

 👉 Store the **minimum valid window**


 ### 🔹 Must Do


 20. Minimum Size Subarray Sum

21. Smallest Subarray with Sum Greater Than X

22. Minimum Window Substring

23. Minimum Window Subsequence

24. Smallest Window Containing 0, 1 and 2

25. Minimum Removals for Target Sum


 **Golden Rule:**


 > For LONGEST → shrink when invalid\

>  For SHORTEST → shrink while valid

 ## 🔵 PATTERN 4 — FREQUENCY / HASHMAP WINDOW


 When the question talks about:


 **Characters + Frequency + Distinct + Anagram + Pattern**


 Think:


 `Sliding Window + HashMap/Frequency Array`


 ### Practice:


 26. Permutation in String

27. Find All Anagrams in a String

28. Longest Substring Without Repeating Characters

29. Longest Substring with K Distinct Characters

30. Count Substrings with Exactly K Distinct Characters

31. Minimum Window Substring

32. Substring with Concatenation of All Words


---


 ## 🔴 PATTERN 5 — “AT MOST K” → “EXACTLY K”


 One of the **most important interview tricks**:


 ### `Exactly(K) = AtMost(K) - AtMost(K-1)`


 Use this for:


 33. Subarrays with K Different Integers

34. Subarrays with Exactly K Distinct Elements

35. Binary Subarrays With Sum

36. Count Number of Nice Subarrays

37. Substrings with Exactly K Distinct Characters


 🔥 Once you understand this transformation, many “exactly K” problems become much easier.


---


 ## 🟣 PATTERN 6 — SLIDING WINDOW + DEQUE


 When you need **Maximum / Minimum of every window**:


 38. Sliding Window Maximum

39. Sliding Window Minimum

40. Max of Minimum for Every Window Size

41. First Negative Integer in Every Window


 Core idea:


 **Monotonic Deque → O(N)**

 # 🧠 QUICK REVISION CHEAT SHEET


 | Question says... | Think... |

| --- | --- |

| Size K | Fixed Window |

| Maximum Sum | Fixed / Variable Window |

| Longest + condition | Expand + Shrink |

| Shortest / Minimum | Shrink while valid |

| K Distinct | HashMap + Window |

| Anagram / Permutation | Frequency + Fixed Window |

| Exactly K | AtMost(K) − AtMost(K−1) |

| Max/Min in every window | Monotonic Deque |

| String + frequency | Sliding Window + HashMap |
