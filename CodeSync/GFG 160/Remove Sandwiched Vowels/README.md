## Problem Description

Given string s containing only lowercase English alphabets, eliminate the vowels from the string that occur between two consonants (sandwiched between two immediately adjacent consonants). Return the new string. Examples: Input : s = "bab" Output : bb Explanation: 'a' is a vowel occuring between two consonants i.e. b. Hence the updated string eliminates a. Input : s = "ceghij" Output : cghj Explanation: 'e' and 'i' are sandwitched vowels. Constraints: 1 ≤ s.size() ≤ 106 'a' ≤ s[i] ≤ 'z'
