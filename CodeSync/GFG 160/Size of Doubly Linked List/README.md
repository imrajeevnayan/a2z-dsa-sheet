## Problem Description

Given a doubly linked list. The task is to find the number of nodes in the doubly linked list. Examples: Input: 1<->2<->3<->4 Output: 4 Explanation: The size of the liked list is 4 which is the number of nodes in it Input: 1<->2 output: 2 Explanation: The size of the liked list is 2 which is the number of nodes in it. Constraints: 1 ≤ number of nodes ≤ 109 1 ≤ node->data ≤ 109
