🚀 Fixed Size Sliding Window — Complete DSA Roadmap

Agar kisi question mein "every subarray/substring of size K", "window of size K" ya "length K" diya hai, sabse pehle dimaag mein aana chahiye:

🔥 FIXED SIZE SLIDING WINDOW


The goal is not to memorize 50 questions.

The goal is to recognize the underlying pattern and change only the data structure/state maintained inside the window.


🧠 Master Template

int left = 0;

for (int right = 0; right < n; right++) {

    // Add right element

    if (right - left + 1 == k) {

        // Calculate / store answer

        // Remove left element

        left++;

    }

}


Core idea:


RIGHT → Add

   ↓

Window Size == K

   ↓

Answer

   ↓

Remove LEFT

   ↓

LEFT++

🟡 Pattern 5 — HashMap / Frequency

6. Count Distinct Elements in Every Window of Size K ⭐


Maintain:


HashMap<Integer, Integer>


Map:


element → frequency


When adding:


frequency++


When removing:


frequency--


If frequency becomes 0:


remove key


Then:


map.size()


= number of distinct elements.


Questions:


Count distinct elements in every window of size K

Frequency of every element in every window

Maximum frequency in a window

Number of elements occurring exactly once

Number of elements occurring more than once

🟠 Pattern 7 — Monotonic Deque

9. Sliding Window Maximum ⭐⭐⭐


LeetCode 239


One of the most important Sliding Window problems.


Maintain:


Deque<Integer> dq


Store indices.


Deque maintains:


largest → smallest


So:


arr[dq.peekFirst()]


is always the maximum.


10. Sliding Window Minimum ⭐⭐⭐
