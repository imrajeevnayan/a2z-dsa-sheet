🚀 Sliding Window Pattern – Complete DSA Roadmap

Sliding Window is one of the most important DSA patterns for LeetCode, GFG, interviews and contests.

Goal ye nahi hai ki 20-30 solutions rat lo.

Goal ye hai:


🧠 Question dekho → pattern identify karo → window banao → state maintain karo → expand/shrink karo.

📌 1. Sliding Window Kya Hai?

Sliding Window mainly in problems involving:

▸Contiguous subarray

▸Substring

▸Consecutive elements

▸Longest/shortest range

▸Maximum/minimum/count of valid ranges


Hum ek window maintain karte hain:


[l ........ r]


where:


l = left pointer

r = right pointer


Basic idea:


➡️ Right pointer se window expand karo

⬅️ Left pointer se window shrink karo


🔍 2. Sliding Window Kaise Identify Karein?


Question mein ye keywords dekho:


▸subarray

▸substring

▸contiguous

▸consecutive

▸longest

▸shortest

▸maximum

▸minimum

▸count

▸at most K

exactly K


Khud se poochho:


"Can I represent the required portion as one continuous window?"


Agar YES, Sliding Window consider karo.


🧠 3. Har Sliding Window Problem Mein 5 Questions


Question solve karne se pehle:


Window kya hai?

Window mein kya information maintain karni hai?

Window invalid kab hogi?

Invalid hone par kya remove karna hai?

Answer kab update karna hai?


Ye 5 questions clear hain → implementation usually easy ho jaati hai.


🟢 LEVEL 1: Fixed Size Sliding Window


Window size already given hota hai.


Example:


Find maximum sum of subarray of size K.


Condition:


window size = K


Template:


int l = 0;

long long sum = 0;


for (int r = 0; r < n; r++) {

    sum += arr[r];


    if (r - l + 1 == k) {

        // update answer


        sum -= arr[l];

        l++;

    }

}


Mental model:


➡️ Add right

📏 Size == K?

🎯 Update answer

⬅️ Remove left


Practice:

Sliding Window Maximum


🟡 LEVEL 2: Variable Size Window


Yahan window size fixed nahi hota.


Condition decide karti hai ki window kitni badi ho sakti hai.


Example:


Longest subarray with sum <= K.


Pattern:


➡️ Expand

⬇️ Condition check

❌ Invalid → Shrink

✅ Valid → Update answer


Template:


for (int r = 0; r < n; r++) {


    add(arr[r]);


    while (invalid()) {

        remove(arr[l]);

        l++;

    }


    ans = max(ans, r - l + 1);

}


Important:


Right pointer = Explore


Left pointer = Repair

Typical questions:

    }


    ans = max(ans, r - l + 1);

🔴 LEVEL 4: Shortest Valid Window


Yahan thinking different hai.


Question:


Minimum length subarray whose sum >= target.


Pattern:


✅ Window valid

↓

🎯 Update minimum

↓

⬅️ Shrink

↓

Window invalid

↓

➡️ Expand again


Template:


for (int r = 0; r < n; r++) {


    add(arr[r]);


    while (valid()) {


        ans = min(ans, r - l + 1);


        remove(arr[l]);

        l++;

    }

}


Golden Rule:


Longest:


Invalid → Shrink → Update maximum


Shortest:


Valid → Update minimum → Shrink

Minimum Size Subarray Sum

Minimum Window Substring


🔵 LEVEL 5: Frequency Map Window


Strings aur character problems mein extremely useful.


Example:


Longest substring with at most K distinct characters.


Maintain:


unordered_map<char, int> freq;


Example:


window = "aabac"


a → 3

b → 1

c → 1


Distinct = 3.


Agar K = 2:


3 > 2 → window invalid.


Shrink from left.


Template:


freq[s[r]]++;


while (freq.size() > k) {


    freq[s[l]]--;


    if (freq[s[l]] == 0)

        freq.erase(s[l]);


    l++;

}

🔥 LEVEL 7: Exactly K Pattern


Very important trick:


Exactly K = At Most K - At Most (K - 1)


Example:


Exactly 3 distinct:


exactly(3) = atMost(3) - atMost(2)


Why?


AtMost(3) contains:


0, 1, 2, 3 distinct


AtMost(2) contains:


0, 1, 2 distinct


Subtract karne par only exactly 3 remains.


Practice:


Subarrays with K Different Integers

Binary Subarrays With Sum

Number of Nice Subarrays

Subarrays with Exactly K Odd Numbers


🧮 LEVEL 8: Counting Valid Windows


Suppose current window is:


[l ........ r]


and window valid hai.


Number of valid subarrays ending at r:


r - l + 1


Example:


[a b c d e]

  l       r


Valid subarrays ending at e:


[e]

[d,e]

[c,d,e]

[b,c,d,e]

[a,b,c,d,e]


Total = 5


Therefore:


ans += r - l + 1;


This is a very important counting trick.

🔴 LEVEL 10: Minimum Window Substring


One of the most important Sliding Window problems.


Problem:


Find the smallest substring containing all characters of another string.


Example:


s = "ADOBECODEBANC"

t = "ABC"


Answer:


"BANC"


Pattern:


Expand → Condition satisfied → Record answer → Shrink → Become invalid → Expand


This problem is a must-solve for interviews.


⚡ LEVEL 11: Sliding Window + Deque


For problems like:

Instead use:


Deque


This can reduce:


O(NK)


to:


O(N)

⚠️ LEVEL 12: When Sliding Window Does NOT Work


Very important.


Normal sum-based Sliding Window generally relies on non-negative numbers.


Example:


[2, -5, 10, -2]


Negative numbers ki wajah se sum monotonic nahi rehta.


So if you see:


Negative numbers + exact subarray sum


think about:


Prefix Sum + HashMap


Example:


Count subarrays with sum exactly K.


For arbitrary integers, Prefix Sum + HashMap is often the correct approach.


🆚 Sliding Window vs Other Patterns


Sliding Window:


Contiguous range + maintainable state


Two Pointers:


Two pointers, but not necessarily a traditional window.


Prefix Sum:


Subarray sum + negative numbers + exact target


Monotonic Stack:


Next greater/smaller type problems


Binary Search:


Monotonic answer/feasibility problems

🧠 Final Mental Model


Whenever you see a contiguous subarray/substring problem, ask:


🔥 What is my window?


🔥 What enters when r moves?


🔥 What leaves when l moves?


🔥 What state am I maintaining?


🔥 When does the window become invalid?


🔥 When should I shrink?


🔥 Am I finding longest, shortest, or count?


🔥 Is "At Most K" or "Exactly K" involved?


If these questions become automatic, Sliding Window problems become much easier.


🚀 Don't memorize solutions.


Master the movement:


Right → Expand


Left → Shrink


State → Maintains the window


Condition → Decides when to shrink


Answer → Extracted from the valid window


Master the pattern, not the problem. 💯
