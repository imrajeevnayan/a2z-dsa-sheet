## Problem Description

Given two strings s1 and s2, consisting of lowercase English letters, find the number of occurrences of s2 as a substring in s1. Overlapping occurrences should also be counted. Examples: Input: s1 = "gfggfg", s2 = "gfg" Output: 2 Explanation: The substring "gfg" occurs in "gfggfg" starting at indices 0 and 3. Therefore, the frequency of s2 in s1 is 2. Input: s1 = "banana", s2 = "nn" Output: 0 Explanation: The substring "nn" does not occur anywhere in "banana". Therefore, the frequency is 0. Input: s1 = "aaaaa", s2 = "aa" Output: 4 Explanation: The substring "aa" occurs starting at indices 0, 1, 2, and 3. Since overlapping occurrences are also counted, the frequency is 4. Constraints: 1 ≤|s2|≤ |s1|≤ 105
