## Problem Description

Given a number n. You have to find the nth number whose each digit is a prime number i.e. 2, 3, 5, 7. In other words, you have to find nth number of this sequence: 2, 3, 5, 7, 22, 23 ,... and so on. Examples: Input: n = 10 Output: 33 Explanation: 10th number in the sequence of numbers whose each digit is prime is 33. Input: n = 21 Output: 222 Explanation: The 21st number in the sequence of numbers whose each digit is prime is 222. Constraints: 1 ≤ n ≤ 100
