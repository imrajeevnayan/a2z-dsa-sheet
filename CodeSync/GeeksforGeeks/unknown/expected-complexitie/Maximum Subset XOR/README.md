## Problem Description

Given an array arr[], choose any subset of elements (possibly all elements) such that the XOR of the chosen elements is maximized. Examples: Input : arr[] = [2, 4, 5] Output: 7 Explanation: The subset {2, 5} has the maximum XOR value. Input : arr[] = [9, 8, 5] Output: 13 Explanation: The subset {8, 5} has the maximum XOR value.
