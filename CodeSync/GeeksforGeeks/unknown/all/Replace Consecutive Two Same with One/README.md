## Problem Description

Given a string s, consisting of lowercase alphabets. Remove consecutive duplicate characters from the string. Example: Input: s = "aabb" Output: "ab" Explanation: The character 'a' at index 2 is the same as 'a' at index 1, so it is removed.Similarly, the character 'b' at index 4 is the same as 'b' at index 3, so it is removed.
