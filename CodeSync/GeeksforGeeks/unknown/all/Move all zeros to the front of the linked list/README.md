## Problem Description

Given the head of a linked list, move all nodes with value 0 to the front while preserving the relative order of all non-zero nodes. Examples: Input: head: 0 -> 4 -> 0 -> 5 -> 0 Output: 0 -> 0 -> 0 -> 4 -> 5 Explanation: After moving all 0s of the given list to the front, the list is: 0 -> 0 -> 0 -> 4 -> 5 Input: head: 0 -> 1 -> 0 -> 1 -> 2 Output: 0 -> 0 -> 1 -> 1 -> 2 Explanation: After moving all 0s of the given list to the front, the list is: 0 -> 0 -> 1 -> 1 -> 2 Constraints: 1 ≤ size of linked list ≤ 105 1 ≤ data of nodes ≤ 105
