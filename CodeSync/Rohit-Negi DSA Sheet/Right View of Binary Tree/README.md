## Problem Description

Given the root of a binary Tree. Return the right view of the binary tree. The right view of a Binary Tree is the set of nodes visible when the tree is viewed from the right side. Examples : Input: root = [1, 2, 3, N, N, 4, 5] Output: [1, 3, 5] Input: root = [1, 2, 3, 4, N, N, N, N, 5] Output: [1, 3, 4, 5] Input: root = [3] Output: [3]
