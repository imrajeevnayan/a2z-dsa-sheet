## Problem Description

Given the root of a binary tree, return its preorder traversal. Note: A preorder traversal first visits the node, then visits the left child (including its entire subtree), and finally visits the right child (including its entire subtree). Examples: Input: root = [1, 4, N, 4, 2] Output: [1, 4, 4, 2] Explanation: The preorder traversal of the given binary tree is [1, 4, 4, 2] Input: root = [6, 3, 2, N, 1, 2, N] Output: [6, 3, 1, 2, 2] Explanation: The preorder traversal of the given binary tree is [6, 3, 1, 2, 2]
